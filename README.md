 IncidentSmartManager
Sistema de Gestión de Incidentes desarrollado con HTML5, CSS3, Bootstrap 5, Chart.js y LocalStorage.
Descripción
IncidentSmartManager es una aplicación web completa para la gestión y seguimiento de incidentes de TI. Permite registrar, clasificar, asignar y resolver incidentes con un dashboard interactivo y reportes detallados.
