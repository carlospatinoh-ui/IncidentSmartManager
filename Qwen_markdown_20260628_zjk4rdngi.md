# 🛡️ IncidentSmartManager

Sistema de Gestión de Incidentes desarrollado con HTML5, CSS3, Bootstrap 5, Chart.js y LocalStorage.

## 📋 Descripción

IncidentSmartManager es una aplicación web completa para la gestión y seguimiento de incidentes de TI. Permite registrar, clasificar, asignar y resolver incidentes con un dashboard interactivo y reportes detallados.

## 🚀 Características

- ✅ **Login con roles** (Administrador, Técnico, Usuario)
- ✅ **Dashboard con KPIs** en tiempo real
- ✅ **CRUD de usuarios** (solo administradores)
- ✅ **CRUD de incidentes** completo
- ✅ **Seguimiento de incidentes** con historial
- ✅ **Reportes y estadísticas** detallados
- ✅ **Gráficas interactivas** con Chart.js
- ✅ **LocalStorage** simulando base de datos
- ✅ **Diseño profesional** con Bootstrap 5
- ✅ **Responsive** - Adaptable a móviles
- ✅ **Listo para GitHub Pages**
